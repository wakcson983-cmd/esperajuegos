# Sala de Espera Navideña (Fabric 1.21.1)

Pantalla de "Esperando jugadores" con chat, contador de jugadores (/100) y 8 minijuegos navideños.

**Comandos** (necesitan permiso de operador):
- `/screan games players @a on`  → activa la pantalla
- `/screan games players @a off` → la desactiva

**Minijuegos:** Serpiente, Busca Minas, Atrapa Regalos, Laberinto del Elfo, 2048, Pong del Grinch, Luces de Navidad (Simon), Vuelo de Rudolph.

**Chat:** Enter o click en la caja para escribir; Enter envía.

**Requisitos:** Minecraft 1.21.1, Fabric Loader 0.16+, Fabric API. Instalar el mod en el servidor y en todos los clientes.

## Obtener el .jar con GitHub
1. Sube todo este proyecto a un repositorio de GitHub (rama `main`).
2. Pestaña **Actions** → "Build mod" → espera a que termine → abajo en **Artifacts** descarga `esperajuegos-jar`.
3. (Opcional) Crea un tag `v1.0.0` y el .jar aparecerá en **Releases**.
